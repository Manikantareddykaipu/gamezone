# 🎮 GameZone

GameZone is a responsive gaming store website designed for gamers to discover and explore games through a modern dark-themed interface.

The project is built as a frontend web project using HTML, CSS, JavaScript, Bootstrap, Bootstrap Icons, Tailwind CSS, and daisyUI.

## 🚀 Features

- 🎮 Gaming store homepage
- 🔥 Trending games section
- 🎯 Preorder games section
- 📅 Upcoming games section
- 🎠 Image carousel
- 🔐 Login page
- 📝 Registration page
- 🌐 Social login interface
- 📱 Responsive design
- 🎨 Dark gaming-themed UI
- 🧩 Reusable header and footer
- ⚡ Dynamic loading of HTML components and game cards

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap
- Bootstrap Icons
- Tailwind CSS
- daisyUI
